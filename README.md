# 💻 MacBook 3D Landing Page

Интерактивный лендинг с 3D-моделью MacBook, плавными анимациями и современным UI.

## ⚡ Features

- 🧊 3D модель MacBook (Three.js / React Three Fiber)
- 🎬 Плавные анимации (GSAP)
- 📱 Адаптивный дизайн
- ⚡ Быстрая загрузка (Vite)
- 🎨 Современный UI (Tailwind CSS)
- 🎥 Видео внутри 3D сцены / UI

---

## 🛠 Tech Stack

- **React 19**
- **Three.js**
- **@react-three/fiber**
- **@react-three/drei**
- **GSAP**
- **Tailwind CSS**
- **Zustand**
- **Vite**
